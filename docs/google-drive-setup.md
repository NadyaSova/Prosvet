# Google Drive: разовая настройка

Чтобы «Просвет» мог сохранять в Google Drive, Google должен знать приложение: нужен проект в Google Cloud и в нём «клиент OAuth». Это бесплатно. Займёт минут 15. Делать на компьютере.

Итог настройки — одна строка, **Client ID** (вида `123…-abc….apps.googleusercontent.com`). Её нужно вписать в `src/config/google.ts`. Пока строки нет, раздела «Google Drive» в настройках приложения нет.

Client ID не секрет: он виден любому, кто откроет приложение. Работает он только с адреса, который указан в проекте (шаг 5).

## 1. Проект

1. Открыть https://console.cloud.google.com и войти тем аккаунтом Google, на чей Drive будут сохраняться данные.
2. Если Google спросит про условия использования — согласиться.
3. Вверху слева — выбор проекта → **New project** (Новый проект). Имя — `Prosvet`. Организацию не выбирать. **Create**.
4. Убедиться, что вверху выбран проект `Prosvet`.

## 2. Включить Google Drive API

1. Меню слева (☰) → **APIs & Services** → **Library**.
2. В поиске — `Google Drive API` → открыть → **Enable**.

## 3. Экран согласия

1. Меню → **Google Auth Platform** (в старом виде консоли — **APIs & Services → OAuth consent screen**). Если там кнопка **Get started** — нажать.
2. **App information:** имя приложения — `Просвет`, адрес поддержки — свой адрес. **Next**.
3. **Audience:** **External**. **Next**.
4. **Contact information:** свой адрес. **Next**.
5. Согласиться с правилами → **Create**.

## 4. Доступ и пользователи

1. **Data access** → **Add or remove scopes** → найти `.../auth/drive.file` («See, edit, create, and delete only the specific Google Drive files you use with this app») → галочка → **Update** → **Save**.
   Это доступ только к файлам, которые создало само приложение. Остальной Drive приложение не видит.
2. **Audience** → **Test users** → **Add users** → свой адрес Google → **Save**.
   Приложение остаётся в режиме «Testing». Так войти может только этот адрес, а проверка приложения у Google не нужна.

## 5. Клиент

1. **Clients** → **Create client** (в старом виде — **APIs & Services → Credentials → Create credentials → OAuth client ID**).
2. **Application type:** **Web application**. Имя — `Prosvet web`.
3. **Authorized JavaScript origins** → **Add URI**:
   - `https://nadyasova.github.io` — адрес приложения, без `/Prosvet/` в конце;
   - `http://localhost:4173` — для проверки сборки на компьютере (можно не добавлять).
4. **Authorized redirect URIs** — оставить пустым.
5. **Create**. Скопировать **Client ID** и прислать его в сессию разработки. Client secret не нужен.

Изменения в Google иногда начинают действовать через несколько минут.

## 6. Первый вход на телефоне

После того как Client ID вписан и новая версия опубликована:

1. Открыть приложение (новая версия — со второго открытия) → Настройки → **Google Drive** → **Сохранить в Drive**.
2. Выбрать аккаунт. Google предупредит: «Google не проверил это приложение» — **Продолжить**. Это потому, что приложение в режиме «Testing».
3. Поставить галочку доступа к файлам, созданным приложением, → **Продолжить**.
4. В Drive появится папка «Просвет»: «Копии», «Боссы», документы «Летопись», «Находки», «Недели».

Дальше разрешение спрашиваться не будет. Вход действует около часа. Потом — снова **Сохранить в Drive**: окно Google мелькнёт и закроется само.

## Если что-то не так

- **«Ошибка 400: redirect_uri_mismatch» или «origin_mismatch»** — в шаге 5 адрес вписан не так. Нужно ровно `https://nadyasova.github.io`, без косой черты в конце.
- **«Ошибка 403: access_denied»** — адрес не добавлен в Test users (шаг 4).
- **Окно Google не открылось** — браузер заблокировал всплывающее окно. Разрешить всплывающие окна для сайта и нажать ещё раз.
