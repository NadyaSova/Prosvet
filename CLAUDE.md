# Просвет

Геймифицирующее PWA для мотивации в поиске работы: RPG, в которой выполненные задания восстанавливают долину, затянутую туманом.

## Главное
- Полная спецификация — `SPEC.md`. Прочитай её целиком перед началом работы и сверяйся с ней.
- В спецификации есть метки:
  - **[РЕШЕНО]** — решение пользователя, не меняй без её согласия;
  - **[ПРЕДЛОЖЕНО]** — можно уточнять и упрощать, о существенных отклонениях спрашивай;
  - **[ОТКРЫТО]** — спроси пользователя или выбери разумный вариант по умолчанию и прямо скажи, что выбрал.
- Ориентир по графике — `docs/reference-valley.svg`.
- Начинаем с фазы 1 (SPEC §13). Фазу 2 не реализуй без запроса.
- План фазы 1, что уже сделано, решения вне спецификации и порядок работы (git, публикация, проверка в браузере) — `docs/phase1-plan.md`. Прочитай его после `SPEC.md` и обновляй в конце каждого шага.

## Правила
- Общение с пользователем — по-русски. Интерфейс приложения — по-русски.
- Данные только на устройстве (IndexedDB), без бэкенда и без внешних запросов во время работы.
- Числа баланса — в одном конфиг-файле.
- Логика серии, таймера и экономики — чистые функции с временем в параметре, покрытые тестами.
- Рендер долины отделён от игровой модели (графику можно будет заменить).
- Деплой — GitHub Pages.
- Разрешение пользователя на всё время проекта: коммит и push в `main` делать без вопроса — когда шаг или правка закончены и тесты со сборкой проходят. Так же без вопроса: ставить npm-пакеты, запускать сборку, тесты, локальный сервер и проверку в браузере (`scripts/check-page.mjs`). Спрашивать по-прежнему, если действие удаляет данные или историю (force push, `reset --hard`, удаление веток) или если решение в спецификации помечено как пользовательское.
