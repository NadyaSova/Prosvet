# Просвет

Геймифицирующее PWA для мотивации в поиске работы: RPG, в которой выполненные задания восстанавливают долину, затянутую хмарью.

## Главное
- Полная спецификация — `SPEC.md`. Прочитай её целиком перед началом работы и сверяйся с ней.
- В спецификации есть метки:
  - **[РЕШЕНО]** — решение пользователя, не меняй без её согласия;
  - **[ПРЕДЛОЖЕНО]** — можно уточнять и упрощать, о существенных отклонениях спрашивай;
  - **[ОТКРЫТО]** — спроси пользователя или выбери разумный вариант по умолчанию и прямо скажи, что выбрал.
- Ориентир по графике — `docs/reference-valley.svg`.
- Начинаем с фазы 1 (SPEC §13). Фазу 2 не реализуй без запроса.

## Правила
- Общение с пользователем — по-русски. Интерфейс приложения — по-русски.
- Данные только на устройстве (IndexedDB), без бэкенда и без внешних запросов во время работы.
- Числа баланса — в одном конфиг-файле.
- Логика серии, таймера и экономики — чистые функции с временем в параметре, покрытые тестами.
- Рендер долины отделён от игровой модели (графику можно будет заменить).
- Деплой — GitHub Pages.
